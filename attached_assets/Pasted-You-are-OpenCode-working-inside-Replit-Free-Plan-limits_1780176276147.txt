MAIN GOAL
=========

Build a clean, lightweight, demo-ready Warqless MVP structure.

The MVP should show the product idea clearly:

1. Student can browse books.
2. Student can view book details.
3. Student can “buy” a book using mock purchase.
4. Purchased book appears in My Library.
5. Student can open the book in a simple protected-looking reader.
6. Reader shows watermark with student info.
7. Student can add basic notes/bookmarks/highlights if easy.
8. Admin can manage books using mock/local data.
9. Publisher can view their books and simple mock sales.
10. Roles should be separated visually:

* Student app
* Admin dashboard
* Publisher dashboard

This version is for prototype/demo only, not production.
